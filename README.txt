AUTOCARE GARAGE — VANILLA HTML / CSS / JAVASCRIPT

Files:
- index.html: page structure
- styles.css: design, responsive layout and animations
- app.js: booking flow, tracking, admin dashboard and localStorage data

HOW TO RUN:
1. Keep all three files in the same folder.
2. Double-click index.html to open it in Chrome/Edge.
3. Click “Admin portal” to open the demo admin dashboard.
4. Bookings and settings are stored in the current browser's localStorage.

NOTES:
- This is a frontend-only demo; no backend, secure admin login, or cross-device sync.
- Google Fonts and the Unsplash workshop photos need an internet connection.
- The design is recreated from the supplied AutoCare Garage React project in plain HTML, CSS and JS.
